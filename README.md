# BTS: A Journey Through Forever (방탄소년단) 💜

A cinematic, scroll-driven digital tribute and luxury music museum dedicated to **BTS (방탄소년단)** and **ARMY**.

---

## 🌟 The 6 Major Scenes

1. **Scene 01: The Grand Entrance (HeroStage)**:
   - Fullscreen cosmic violet stage environment with volumetric lighting and floating stardust.
   - 7-member group composition standing in stage formation with realistic rim lighting and reflective stage floor.
   - Seven distinct stage spotlights illuminating each member at the bottom.
   - Subtle scroll indicator and unobtrusive audio controls.

2. **Scene 02: Seven Members, Seven Stories (MemberChoreography)**:
   - 7 dedicated scroll chapters for **RM, Jin, SUGA, j-hope, Jimin, V, Jung Kook**.
   - Spotlight focuses on active member while camera zooms into their portrait.
   - Alternating editorial layout (Left, Right, Left, Right...).
   - Deep dive into verified biographies, artistic roles, solo discographies (*Indigo, Happy, D-DAY, Jack In The Box, MUSE, Layover, GOLDEN*), tracklists, and key achievements.

3. **Scene 03: The Living Discography (AlbumJourney)**:
   - Chronological release catalog from 2013 debut (*2 Cool 4 Skool*) to Anthology (*BE & Proof*).
   - 3D opening album photobook sleeve with a sliding vinyl record that settles into an antique golden gramophone.
   - Spinning turntable with needle drop audio FX and audio visualizer.
   - Accessible song-detail modal popup with songwriting credits, producers, lyric highlights, and themes.

4. **Scene 04: The Memory Room (MemoryRoom)**:
   - Cozy, warm interior with neon pink "BTS forever 💜" wall sign and ambient lighting.
   - 7 members seated together on the plush sofa on the right.
   - Vintage 4K television on the left playing a 5-minute memory film spanning 5 historical eras with full video scrubber, timestamps, and quotes.

5. **Scene 05: The BTS Resource Universe (ResourceGallery)**:
   - 15 curated and verified categories including Official MVs, Live Concerts, Dance Practices, Behind-the-Scenes, Historic Speeches (UN, White House), Variety Shows (*Run BTS*, *In the SOOP*, *Bon Voyage*), Documentaries, and UNICEF LOVE MYSELF campaign.
   - Direct links to official BANGTANTV, HYBE LABELS, Weverse, and Spotify channels.

6. **Scene 06: The Final Goodbye (FinaleScene)**:
   - Full 7-member group reunited under converging spotlights.
   - Emotional typography: *"Seven hearts. Countless memories. One forever."* and *"Thank you, ARMY, for being part of this story."*
   - Interactive Purple Confetti Shower (Borahae!).
   - Live interactive Borahae Fan Guestbook Wall where fans can post messages.
   - Replay journey button.

---

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite + TypeScript
- **3D Graphics**: Three.js (WebGL volumetric spotlights & particle galaxy)
- **Styling**: Tailwind CSS + Glassmorphic UI
- **Typography**: Cinzel, Cormorant Garamond, Great Vibes, Montserrat
- **Icons**: Lucide React
- **Audio**: Web Audio API (soothing piano synthesizer & audio streams) + Sound FX
- **Animations**: CSS 3D Transforms + GSAP compatible architecture + Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+ installed
- npm or yarn

### Installation
```bash
# Clone or navigate to the project directory
cd dazzling-pasteur

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be running at `http://localhost:5173/`.

### Production Build
```bash
# Compile TypeScript and bundle with Vite
npm run build

# Preview production build locally
npm run preview
```
